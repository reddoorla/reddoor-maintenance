# 2026-10-26 — P1-70: the Claude probe seam stops breaking on SDK minors

Landed: this PR (branch `claude/p1-70-sdk-fixtures`), which unblocks Renovate's all-non-major group #1721. Brief: the home base's `morning-reports/MORNING_REPORT_2026-10-26.md`, P1-70.

**Why the group was red.** #1721 bumps `@anthropic-ai/sdk` 0.120 → 0.137. 0.137 added two required-but-nullable fields, `Message.diagnostics` (`Diagnostics | null`) and `Usage.speed` (`'standard' | 'fast' | null`). The hand-built fixtures in `tests/prospect/probes.test.ts` spelled out every field of both types, so `pnpm typecheck` failed with TS2741 at 542 and 558, the exact errors in ci run 40256694972. I reproduced them in the worktree by checking out #1721's `package.json` and lockfile on top of `main`.

**The fix is in the seam, not the fixture.** `claudeWebSearchEngine` reads only `content` and `stop_reason`. `ClaudeMessageCreate` now returns `Pick<Anthropic.Message, "content" | "stop_reason">`, the real client's `Message` still satisfies it with no cast, and the fixture builds those two fields alone. Adding `speed` and `diagnostics` to the fixture would have gone green today and red again at the next such field. Typecheck, lint and 1011 prospect tests pass on 0.120 (main's lockfile) and on 0.137.0.

**Belief corrected: the brief's second mutation would have survived.** "Return the first content block instead of the text block" passed every existing test, because every fixture put the text block first. Real web-search responses put the prose after `server_tool_use` and `web_search_tool_result`, so I added a test with the tool result ahead of the text. Measured: M1 (drop the `pause_turn` check) turns 5 tests red; M2 turns 3 red, the new test among them.

**Left as is.** The block fixtures (`TextBlock`, `WebSearchResultBlock`, `WebSearchToolResultBlock`) are still full SDK types, so a new required field on a block can red typecheck the same way. That is deliberate: those shapes are what the engine narrows on and pushes back as `MessageParam` content, and loosening them would weaken the check. One review round, clean (one minor, that one, and two comment nits, folded in).
