**Beliefs corrected on contact.**

- **`AxeBuilder#options()` replaces the builder's whole option object.** Called after `.withRules()`, it silently dropped `runOnly`, and the spec ran every axe rule under a title naming two. The spec now sets options first and asserts exactly two rules ran.
- **axe sets aside a failing one-character text as "incomplete" (`shortTextContent`), not a violation.** That is why Lighthouse never named the "V". `ignoreLength` turns that off. Setting it aside applies only when the text _fails_, so dropping `ignoreLength` while the "V" passes correctly changes nothing.
