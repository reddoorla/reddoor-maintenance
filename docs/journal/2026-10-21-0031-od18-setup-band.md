# 2026-10-21 — OD 18 step 2: roster gaps leave the Watch band for a Setup checklist

**Where it landed:** this PR (reddoorla/reddoor-maintenance, branch `claude/od18-setup-band-v2`), step 2 of #672, after the cockpit cutover (#1574). The operator's answer of 2026-10-20 (workspace `decisions/2026-09-29-0653-od-18-standing-product-calls.md`): roster gaps move to a Setup band.

**Why.** Five roster gaps used to raise Watch: no GA4 property, no Search Console property, no git repo, no Netlify ID, and a maintained site still on `*.netlify.app`. They describe an unfinished roster row, not a site getting worse. Counted as Watch, they kept the verdict amber, and they buried the watch reasons that are about decline (a Lighthouse category in [75, 85), a repo stale past 30 days, an unresolved URL, Turnstile unverified) among chores. A site whose only conditions are roster gaps is now healthy.

**What a visitor sees.**

- **On `/`,** a `🧰 Setup (N sites)` lane sits between Needs-you and the Fleet panel. It is collapsed and lists each site with its gaps. It is counted apart from the verdict bar, because Setup never moves a tier.
- **On each card,** a checklist under the chips names each gap and the exact text that accepts it, as a watch chip does.
- **On `/s/:slug`,** the same checklist sits under the existing onboarding line. Without it, the gaps that used to show there as Watch chips would have vanished from the site page.
- **The filter chips** (`no-analytics`, `no-git-repo`, …) still match a card with that gap. The gaps left `watchSignals`, so the card's filter tags add them back from the Setup list.
- **`scripts/pm-cockpit.mts`** prints `setup=N` in its summary line and a `## Setup` section. `broken`, `watch` and `approval` never count it.

**The digest needed no change, and that is a finding, not a gap.** The brief asked that the digest "read the new band and not count Setup as Watch". Nothing in `src/reports`, `src/alerts` or `src/cli` reads tiers, `watchReasons` or the watch signals. The digest sees only attention items, so it never counted roster gaps as Watch in the first place. A Setup section in the digest would be a new feature, not this step.
