## 2026-10-19 — A read-only `sweep` agent on Haiku 5.5 at `medium`, measured in its own configuration (P1-56, #1425)

P1-55's row-4 bake-off found Haiku 5.5 at `medium` matching gold on 456/456 census checks at about $0.013 a run. Nothing used it. This adds `.claude/agents/sweep.md` (`model: haiku`, `effort: medium`, `tools: Read, Grep, Glob`), a frontmatter test, and one CLAUDE.md paragraph that routes mechanical sweeps to it. The global `xhigh` pins and `CLAUDE_CODE_SUBAGENT_MODEL` are unchanged.

**The number the brief cited did not measure this agent.** Review round 1 caught it: every row-4 arm had Bash and Write, and both Haiku `medium` runs wrote or ran a counting script. A read-only agent has to read 38 files into its context instead. I froze row 4's census again from `main` at `2459645a`. Before any run, I proved the scorer: the truth scored against itself was 228/228. A copy with three changes failed exactly the 7 checks those changes touch. Three headless spawns of `subagent_type: "sweep"` then scored 228/228 each, at $0.058, $0.136 and $0.134. The third ran on the final agent body, after review edits. That is 4–10x row 4's Haiku cost, and 9 of the 21 requests crossed 100K prompt tokens. It is still Haiku, and Sonnet and Opus were never run read-only, so there is no read-only cost comparison across models. The CLAUDE.md line first set the read-only cost against row 4's Bash-armed Sonnet. Round 2 flagged that as a minor (#1429).

**What ran, read from the transcripts, not the setting.** Every sweep transcript shows exactly one `message.model`, `claude-haiku-5-5`, and one `effort`, `medium`. The agent was spawned with no `model` or `effort` on the call, by a parent headless session on Sonnet at `low`. So the frontmatter set both values; inheritance did not. The docs give the precedence: a per-call `model` beats the frontmatter, which beats `CLAUDE_CODE_SUBAGENT_MODEL`. `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` and `CLAUDE_CODE_EFFORT_LEVEL` override it. The laptop's `effortLevel: xhigh` is a session setting, which the frontmatter beats.

**The write refusal is structural, and the proof needed a control.** The sweep agent, asked to call Write and `gh api user`, made neither call. It said it had no such tools. That is self-report. Its body also forbids writes, so the refusal could have come from the body alone. A control pair in a scratch project settled it. Both agents had the same neutral body. `probe-ro` (Read, Grep, Glob) said it had no Write tool. `probe-rw` (the same plus Write) called Write, and the permission layer refused it with "Claude requested permissions to write to … but you haven't granted it yet". So the `tools` line withholds the tool. The brief's "a write attempt is refused" is met in a stronger form: no attempt is possible.

**Defects found on the way.**

- `.gitignore`'s `.claude/*` silently excluded `.claude/agents/`, so the agent file would never have been committed. It is re-included now, like `workflows/`, `rules/` and `hooks/`.
- Agent files are not hot-loaded. An Agent call with `subagent_type: "sweep"` in the session that wrote the file failed with "Agent type 'sweep' not found". The Workflow `agent()` call's `agentType` resolves from the same registry. Every proof run therefore went through `claude -p` started in the worktree.
- **Two instruments failed before they passed.**
  - The first read-only pair scored 2/228, because the headless spawn denied every read under `/tmp`, which is outside its project. Both agents returned empty lists and said why in `unverified`. Neither guessed. The reruns used `--add-dir`.
  - Later, a `pgrep -f "claude -p"` wait loop reported run 5 "still running" ten minutes after it had finished: the pattern matched the waiting shell's own command line. The transcript's last timestamp (16:01:25) and `date -u` (16:12:00) settled it.

**Reviews.** Round 1 was dirty, with one major, the unmeasured configuration. The measurement above fixed it, along with the cheap minors: the `"node:"` lesson in the body (the miss was by Haiku `low`, on a literal with nothing after the colon), a data-not-instructions line, a no-secret-values line, the env-var caveat, and a test that pins the body's tool claim. Round 2 found only minors, filed as #1429 and #1430. #1431 holds round 1's leftovers. The main one is a deny rule for `.env` and `/proc`. That is a permissions change for the operator, and it is still unverified whether settings deny rules reach subagents. Mutations, each red on the test: drop `effort`, add `Write` to `tools`, `model: sonnet`, and a body that says it may write.
