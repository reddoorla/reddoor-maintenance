**Beliefs corrected on contact.**

- CDP's accessibility tree read `aria-valuetext` as "" even on a known value (round 2). Read the DOM attribute.
- The count-up's layout every frame made the ticker's stale `pointerover` ([#2134](https://github.com/reddoorla/reddoor-maintenance/issues/2134)) far likelier. `tickerReady` now also waits for the count to settle. The browser file went from 188 s to about 380 s.
