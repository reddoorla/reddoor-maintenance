The `haiku` control ran on `claude-haiku-5-5`. But the CLI process's start-up environment (`/proc/<pid>/environ`) does not hold the variable. The practical rule is the one the workspace `CLAUDE.md` already states: the default holds only in sessions that start in the workspace, and elsewhere every call names its tier.

**Beliefs corrected on contact.**
- **The token classes were mispriced.** The brief's token-class split was computed by pricing unsplit cache writes at the 5-minute rate, as `ledger.mjs` does. Review round 2 found the server's `cost_usd` above that figure on almost every real Opus `modelUsage` row, and always below the price at the 1-hour rate. So those writes are mostly 1-hour writes, and the 5-minute pricing understated cache write. The report now books each row's unsplit write as what its `cost_usd` leaves after the other classes, clamped to that band. On the real data the classes then match the server's cost to the cent, and the cache-write share comes out a few points higher than the brief's.
- **`finalize` writes residual rows with no `as_of`.** It does this when a session has a `get_session` reading but no stored result. A window on `as_of` silently dropped them (review round 1; one such row in the real ledger). The report dates them by the session's `cost_read_at`.

**Defined, not discovered.**
- A run's row counts whole in the week of its `as_of`. A session still running across a Monday is counted again the next week, so the weekly lines must never be added up.
- The subagent split includes laptop transcripts, so it covers a different set of sessions from the cloud total.
