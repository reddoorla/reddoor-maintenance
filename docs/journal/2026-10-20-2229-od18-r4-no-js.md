## 2026-10-20 — OD 18 / #674: R4, the no-JS visibility check (this PR)

R4 is the second of the never-reviewed rules the operator put first: nothing needs JavaScript to become visible. It is added to `src/audits/design-rules/` as R4, beside R2. The check renders `<main>` twice, at 1440×900 and 390×844:

- **With JavaScript**, under reduced motion, after `revealBelowFold` has scrolled the page and let every reveal settle.
- **Without JavaScript**, and with no reduced-motion preference.

Every text visible in the first render must be visible in the second. The no-JS render must not emulate `reduce`: the starters hide a reveal behind `prefers-reduced-motion: no-preference`, so a no-JS render under `reduce` passes vacuously. vida's own smoke spec warns of that, and a fixture holds it.

**Proved on a known-good page, then on a real past page.** The instrument passed live vidalegacy.org before any FAIL was read: 94 visible items, summed across both widths, none missing, on the first run. It passed again after round 2, at 2026-10-21 00:10Z, with 116 items. vida-legacy-foundation built here at `baaf301`, the commit before #51 and #52, fails with seven findings at 00:10Z:

- the hero's `<h1>`, its label and its "Donate now" button, hidden by their `.reveal` ancestor (#51). An earlier note here placed the button in the closing panel; the path says the hero;
- the four stats, reading "0+", "0 people", "0%" and "0 lives" without script, which are #52's own words.

Between rounds 1 and 2, the hero's arrow image was an eighth finding. It sits in a clipped bar beside visible copy, so round 2's parked rule leaves it out.

**A finding on a live site.** Beachfront's SectionGrid cards fail at 390 px: three cards' body copy is not rendered without JavaScript. `isMobile` is decided in script, so a phone without JS gets the desktop accordion, collapsed, and it cannot be opened. It is reported here only; I filed nothing in that repo. Two runs at 00:10Z gave the same three findings and nothing else.

**Defects of my own, found on contact.**

- **Pairing by path broke two ways.** The first pass paired the two renders by path, so the four stats, which share one path, all paired with the first "0+". After that was fixed, script-added classes (`.in`) changed the paths between the renders. Elements now pair by a class-free path and its occurrence.
- **A hang.** A frame-and-timer settle in the no-JS render never resolves with scripting off, and hung every test until it was removed.
- **The tsx-only failure.** The first live run was UNMEASURED on every page with `__name is not defined`, while every test was green. A named arrow inside the in-page sampler gets wrapped by tsx's keep-names transform, which vitest does not apply. A test now runs the real CLI under tsx on every rule. It was proved red with the arrow put back and green without it.

**Review round 1 was dirty**, and every finding is fixed with a fixture.

- **False passes:**
  - copy hidden by a mask, a `clip-path` wipe, a collapsed box, transparent ink, `visibility`, a faint opacity or `filter: opacity(0)`;
  - a preloader covering the page;
  - an image, a labelled control or an SVG a reveal hides;
  - slotted copy an undefined custom element hides;
  - a reveal far below the fold;
  - a shadow root under a hidden host;
  - a hidden heading whose words show in a link.
- **False fails:**
  - a CSS-only fade-in;
  - words a script splits into spans;
  - a marquee's cloned copy;
  - a widget with a `<noscript>` alternative;
  - a copyright year a script updates.
- **Unheld:** a page with no `<main>`, and the settle wait before the JS render is read. The settle now waits for the network, reveals below the fold, waits 2 s, then samples every 500 ms until two samples agree.
- **The tsx-only failure got a second guard:** a test reads each in-page function's source under tsx and fails on any `__name` wrapper. It was proved red with a named arrow put back.

**Review round 2 was dirty**, with fixes for each finding:

- **A false fail, from the wiring lens.** An element script inserts ahead of same-tag siblings shifted every later sibling's place, so each one read as "reads X without JavaScript". Text served at a place that script shows somewhere else now counts as moved, not replaced, and is judged by text. Only the inserted element fails.
- **A false fail that sampling time decided, from the defensive lens.** Live, beachfront's autoplay testimonial carousel at 390 px failed on whichever slide the settle landed on ("3 of 11", "Stacey"); a 6-slide fixture failed slide 2 or slide 4 depending on its timer. Without JavaScript the first slide shows and the rest are clipped. An element clipped out of a box that shows other visible content is now parked and not judged, both at its place and when a looping carousel's clone moves it. The carousel that cannot be advanced without JavaScript is admitted as not covered, not judged.
- **A false fail.** A date or opening hours that script rewrites ("January 5, 2026" to "9 months ago"). Both texts being dates or times now passes, as a year does.
- **Two false passes.** An iframe that only script mounts (a booking widget) is now an item. An image with no source until script copies `data-src` in is not visible.
- **Minors folded in.** The note's count is the sum across widths and now says "across". Two comment lines are rewrapped.
- **Admitted, not built.** A count-up that ships a non-zero start reads as a year. A mask inside a box that also shows other content reads as parked.
