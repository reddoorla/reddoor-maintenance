**Beliefs corrected on contact.**

- **A symlinked `node_modules` in the worktree does not work.** pnpm 11's deps check refuses `pnpm build` over it, so vitest's global setup failed. The unmutated pre-run caught that on its first real use. An offline `pnpm install` takes 4.4 s.
- **vitest 4.1's JSON reporter drops the "Test timed out" text.** A timed-out case carries only the stack of an error vitest pre-made, which begins `Error: STACK_TRACE_ERROR`. A file whose cases are all skipped reports `status: "passed"`.
- **`node --check --experimental-strip-types` does not check TS syntax.** It accepts `const x: number = ;`, so TS goes through the repo's own `typescript` `transpileModule` diagnostics.
- **vitest's file filter is a case-insensitive substring match.** A named path can pull in another file, so the overlap check compares in lower case.
- **`git hash-object --path` ignores the index.** So a CRLF file committed before `* text=auto` hashes differently from its blob. `git cat-file --filters` gives the bytes a checkout writes.
- **The script caught a vacuous test of its own.** Its run at `e60ec47a` found M18 surviving: round 3's package-type check had made the "broken at HEAD" fixture (a `.js` with a top-level `return`) parse as CommonJS.
