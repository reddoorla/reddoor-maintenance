Prospect audit checks the Technical report relies on now say what is true (W4, from the 11-23 audit-system review). DMARC has three states: `p=none` is "monitoring only", a fail with its own wording, and no longer passes as "A DMARC record, so SPF is enforced". `noindex` on legal, thank-you, search and login paths passes as deliberate. Only thrown errors count as script errors: the crawl records `vitals.scriptErrors` apart from `console.error` lines, which are notes, and a run stored before the split reads as unmeasured. A link containing `{{` is a template defect, not a page missing from the sitemap. HubSpot's tracking and banner hosts name "HubSpot tracking" (analytics), not "HubSpot CMS". The crawl's browser context asks for reduced motion, and axe leaves the documents of cross-origin frames out of its run while keeping a missing `title` on the site's own `<iframe>`. Security-header reasons state the observation and its ordinary consequence, `frame-ancestors` satisfies the X-Frame-Options check, and the version-leak evidence names the software, never its version. New `prospect-audit --technical` skips analyze, probes and accuracy, so a fresh run spends no model tokens.
